# Student Dev Perks

Slides for a GDG on Campus Universitas Gunadarma session: free developer tools, cloud credits and courses you can claim with a student email.

Live at [s.ajra.tech](https://s.ajra.tech). The PDF is in `student-dev-perks.pdf`.

## Build

```sh
npm install
node fetch-assets.js   # downloads the brand logos into logos/
node render.js         # writes student-dev-perks.pdf from index.html
```
